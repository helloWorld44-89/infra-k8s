# OpusMaxim User Guide

## Access

Navigate to `https://opusmaxim.conderhome.xyz`

Login or register (if enabled).

## Portfolio

- Homepage shows featured projects
- Click project for details
- Filter by category/tag

## Profile

- Click avatar → Profile
- Update bio, links, skills
- Upload avatar (drag & drop)

## Projects

- Create: Dashboard → New Project
- Fields: Title, description, tech stack, links, images
- Visibility: Public / Private

## Admin

- User management (if enabled)
- Content moderation
- Site settings

## Troubleshooting

| Issue | Fix |
|---|---|
| Can't login | Check credentials, clear cookies |
| Avatar not showing | Check upload size limit, file type |
| 500 error | Check Flask logs |
